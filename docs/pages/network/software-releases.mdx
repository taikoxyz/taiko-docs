# Software Releases [Latest release versions for Taiko protocol contracts, taiko-geth, taiko-client, simple-taiko-node, and raiko2 — with links to changelogs.]

## Software Releases

It is **highly recommended** you use the latest software. You can find the latest versions here:

Each [simple-taiko-node release](https://github.com/taikoxyz/simple-taiko-node/releases/latest) pins a matching set of `taiko-client`, `alethia-reth`, and `taiko-geth` images in its `docker-compose.yml` (`docker-compose-hoodi.yml` for Taiko Hoodi). To look up each component on its own:

- `taiko-client`: [release notes](https://github.com/taikoxyz/taiko-mono/blob/main/packages/taiko-client/CHANGELOG.md), released from `taiko-mono` as `taiko-alethia-client-v*` tags
- `alethia-reth`: [latest release](https://github.com/taikoxyz/alethia-reth/releases/latest)
- `taiko-geth`: [latest release](https://github.com/taikoxyz/taiko-geth/releases/latest)
